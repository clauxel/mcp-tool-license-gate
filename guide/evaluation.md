# Evaluation Guide

Use this page to evaluate whether MCP Tool License Gate fits a real workflow.

## What To Test

- MCP tool license check
- MCP server license policy
- MCP third party tool audit
- remote MCP license gate

## Expected Evidence

- Submit tool metadata, license text, intended use, and customer policy.
- Score license fit and policy conflicts before the tool call runs.
- Return allow, review, or deny with structured reasons.
- Archive a license receipt for security and customer audit.

## Risk Checks

- Do not paste proprietary license text into public issues.
- Confirm legal interpretation before customer-facing decisions.
- Keep allowlists tied to named customer policies.
